# OpenSky Coursework

Курсовая работа по получению и анализу данных о самолетах, находящихся в воздухе, с использованием открытых API.

## 📝 Описание проекта

Проект собирает данные о воздушных судах из API OpenSky Network, получает географические координаты стран и сохраняет всё это в базу данных PostgreSQL. Для работы с базой данных реализован класс DBManager, который позволяет получать статистику по странам и самолетам.

## 🛠 Технологии

* Python 3.14
* PostgreSQL (база данных)
* Poetry (управление зависимостями)
* Requests (работа с API)
* psycopg2 (работа с БД)
* Pytest (тестирование)
* Black, Isort, Flake8, Mypy (линтеры и форматирование кода)

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   `git clone https://github.com/nnc-k/opensky-coursework.git`
   `cd opensky-coursework`

2. Установите зависимости (потребуется Poetry):
   `poetry install`

3. Создайте базу данных `opensky_db` в PostgreSQL.

4. Настройте параметры подключения в файле `src/config.py` (впишите ваш пароль от БД).

5. Примените SQL-скрипт для создания таблиц. Выполните содержимое файла `src/create_tables.sql` в вашей базе данных (например, через pgAdmin).

6. Запустите загрузку данных из API:
   `poetry run python -m src.loader`

7. Запустите главный скрипт для просмотра статистики:
   `poetry run python -m src.main`

## 🧪 Тестирование

Для запуска тестов и проверки покрытия используйте:
`poetry run pytest`

## 📁 Структура проекта

* `src/` — исходный код
    * `api_client.py` — работа с API (Nominatim, OpenSky)
    * `config.py` — настройки БД и список стран
    * `country_bounds.py` — статические координаты стран
    * `create_tables.sql` — скрипт создания таблиц
    * `db_manager.py` — класс DBManager для работы с БД
    * `loader.py` — скрипт загрузки данных в БД
    * `main.py` — главный модуль (вывод статистики)
    * `models.py` — dataclass-модели
* `tests/` — модульные тесты
